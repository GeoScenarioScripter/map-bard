# Two October days on the Potomac (night)

The night variant of the [Potomac example](../potomac/README.md). It shares that project's data, photograph and `story.json`; its `mapbard.json` differs only in `theme` (`night`) and `basemap.style` (OpenFreeMap Dark). See the atlas README for the story, the encoding, the motion and the commands, with `--project examples/projects/potomac-night`.
