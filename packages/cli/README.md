# mapbard

The MapBard command-line tool validates plain-file projects and publishes static
map stories. Use `npx mapbard init my-story`, then `npx mapbard --project my-story
check` and `npx mapbard --project my-story build`.

See the [project quickstart](https://github.com/GeoScenarioScripter/map-bard#five-minute-quickstart).
